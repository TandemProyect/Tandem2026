# Checklist antes de publicar en LinkedIn

Checklist para revisar cada post, video o captura de `trdesing.net` antes de publicarlo.

## Identidad y privacidad

- [ ] La publicacion sale desde la pagina de `trdesing.net`, salvo decision expresa de publicarla desde perfil personal.
- [ ] No aparecen nombres personales que no se quieran exponer.
- [ ] No aparecen fotos personales si se quiere mantener distancia publica.
- [ ] No se presenta el proyecto como empresa consolidada si sigue siendo laboratorio.

## Datos y seguridad

- [ ] El video usa datos ficticios.
- [ ] No aparecen clientes reales.
- [ ] No aparecen emails, telefonos, direcciones ni datos personales.
- [ ] No aparecen tokens, claves, credenciales, configuraciones internas o rutas sensibles.
- [ ] No aparecen repositorios privados ni paneles internos.
- [ ] Se han revisado las pestanas del navegador y la barra de direcciones antes de grabar.

## Mensaje

- [ ] El texto deja claro que el proyecto esta en fase temprana.
- [ ] No promete lanzamiento inmediato.
- [ ] No afirma que haya clientes si aun no los hay.
- [ ] Incluye una pregunta o llamada a opinar.
- [ ] El tono es de aprendizaje en publico, no de venta agresiva.

## Video

- [ ] Duracion ideal: 30 a 60 segundos.
- [ ] Se entiende el problema en los primeros segundos.
- [ ] La demo muestra una sola idea principal.
- [ ] La calidad de audio es suficiente.
- [ ] No hay notificaciones visibles.
- [ ] Se han eliminado o evitado metadatos innecesarios cuando aplique.

## Publicacion

- [ ] Revisar ortografia.
- [ ] Confirmar que el enlace `trdesing.net` funciona o decidir no incluirlo todavia.
- [ ] Anotar fecha de publicacion.
- [ ] Guardar enlace del post publicado para seguimiento.

## Seguimiento

- [ ] Registrar comentarios interesantes.
- [ ] Registrar preguntas repetidas.
- [ ] Detectar si la gente entiende la idea sin explicacion adicional.
- [ ] Convertir aprendizajes en mejoras del producto o proximos posts.
