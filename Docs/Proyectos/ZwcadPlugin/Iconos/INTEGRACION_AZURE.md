# 🔗 Integración GitHub ↔ Azure DevOps

## ✅ Configuración Completada

Este archivo confirma que la integración entre GitHub y Azure Boards está configurada.

### 🎯 Sintaxis de Commits

**Para vincular a work items:**
```sh
git commit -m "feat: Nueva funcionalidad AB#612"
```

**Para cerrar automáticamente:**
```sh
git commit -m "fix: Bug corregido Fixes AB#612"
```

### 📋 Palabras Clave

| Palabra | Acción |
|---------|--------|
| `AB#612` | Vincula solamente |
| `Fixes AB#612` | Resuelve al hacer merge |
| `Closes AB#612` | Cierra al hacer merge |
| `Resolves AB#612` | Resuelve al hacer merge |
