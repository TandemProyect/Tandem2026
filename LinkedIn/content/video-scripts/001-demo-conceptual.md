# Guion 001 - Demo conceptual

Estado: borrador

Duracion objetivo: 30 a 60 segundos.

## Objetivo del video

Mostrar que un comentario en video puede explicar una idea, bug o mejora sobre una pantalla con mas claridad que un texto largo.

## Estructura

### 1. Apertura

Mostrar una pantalla ficticia de una web o app.

Voz:

```text
Estamos probando una idea para trdesing.net: explicar feedback sobre productos digitales hablando directamente sobre la pantalla.
```

### 2. Problema

Senalar una zona de la interfaz.

Voz:

```text
Por ejemplo, si un boton no se entiende bien, en lugar de escribir un mensaje largo podemos explicar el problema en contexto.
```

### 3. Comentario

Describir una mejora concreta.

Voz:

```text
Aqui cambiaria el texto, daria mas espacio al bloque principal y destacaria mejor la accion que esperamos del usuario.
```

### 4. Cierre

Voz:

```text
Es solo una demo conceptual, pero queremos validar si este formato ayuda a comunicar mejor bugs, mejoras e ideas de diseno.
```

## Reglas de grabacion

- Usar una pantalla ficticia.
- No mostrar datos reales.
- No mostrar navegador con cuentas personales.
- No mostrar repositorios, rutas locales ni paneles internos.
- Mantener el video corto y centrado en una sola idea.
