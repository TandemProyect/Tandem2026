# Assets LinkedIn

Carpeta para recursos visuales de la pagina y publicaciones de `trdesing.net`.

## Pendientes

- Logo cuadrado para pagina de LinkedIn.
- Banner horizontal para cabecera.
- Plantilla para miniaturas de video.
- Imagen base para posts sin video.

## Recomendaciones

- Mantener una identidad simple y provisional.
- Evitar fotos personales en esta fase.
- Usar colores y formas consistentes con `trdesing.net`.
- Guardar fuentes editables si se crean en herramientas externas.
