# Videos originales

Guardar aqui los videos originales antes de editar.

Esta carpeta esta ignorada por Git para evitar subir archivos grandes o material con datos sensibles accidentales.

Antes de mover cualquier video a una version publicable, revisar:

- No hay datos reales.
- No hay notificaciones visibles.
- No hay cuentas personales.
- No hay rutas locales, repositorios ni informacion interna.
