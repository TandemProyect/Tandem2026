# LinkedIn - Proyecto trdesing.net

Proyecto operativo para construir y mantener la presencia de `trdesing.net` en LinkedIn.

Este proyecto contiene borradores, guiones, assets, videos preparados y seguimiento de publicaciones. La documentacion estrategica esta en [`../Docs/Proyectos/LinkedIn/`](../Docs/Proyectos/LinkedIn/).

## Vista previa

Abrir [`index.html`](index.html) para ver una vista interna de preparacion de la pagina de LinkedIn.

Este archivo no es la pagina publica final. Sirve para revisar mensaje, posicionamiento y primer post antes de crear o publicar la pagina definitiva.

## Objetivo

Crear una pagina de LinkedIn para `trdesing.net` y publicar avances como laboratorio de diseno y producto durante aproximadamente dos anos.

## Estructura

```text
LinkedIn/
├── content/
│   ├── posts/           # Borradores de publicaciones
│   └── video-scripts/   # Guiones para demos y videos
├── assets/
│   ├── logo/            # Logo e iconos de pagina
│   └── banner/          # Banners y cabeceras
├── media/
│   ├── raw/             # Videos originales no versionados
│   └── exports/         # Videos finales no versionados
└── tracking/            # Seguimiento de publicaciones y aprendizajes
```

## Flujo de trabajo

1. Preparar el texto en `content/posts/`.
2. Preparar el guion del video en `content/video-scripts/`.
3. Grabar con datos ficticios y guardar el original en `media/raw/`.
4. Exportar la version final a `media/exports/`.
5. Revisar [`../Docs/Proyectos/LinkedIn/CHECKLIST-PUBLICACION.md`](../Docs/Proyectos/LinkedIn/CHECKLIST-PUBLICACION.md).
6. Publicar desde la pagina de LinkedIn de `trdesing.net`.
7. Registrar resultados y aprendizajes en `tracking/publicaciones.md`.

## Principios

- Publicar como laboratorio, no como producto terminado.
- No usar clientes reales en demos.
- No mostrar informacion personal o sensible.
- Mantener el tono honesto: exploracion, aprendizaje y validacion.
- Usar la cuenta personal solo como administradora de la pagina.
