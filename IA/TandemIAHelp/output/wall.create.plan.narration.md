# Narracion base - Dibujar muro en planta

- Help id: `wall.create.plan`
- Funcion: Muro 2D
- Duracion objetivo: 75 segundos
- Comando AutoCAD: `TANDEM_MURO2D`

## Voz en off base

En este video vamos a ver como usar Dibujar muro en planta.

Permite dibujar un muro en planta creando una cadena de tramos con eje y caras laterales.

Paso 1: Pulsar el icono de dibujar muro en planta.

Paso 2: Seleccionar el punto inicial del muro.

Paso 3: Seleccionar el siguiente punto para crear el primer tramo.

Paso 4: Continuar marcando puntos para crear mas tramos o pulsar Enter para terminar.

Paso 5: Usar la opcion Cerrar cuando exista una cadena con suficientes tramos y se quiera cerrar el recinto.

Al terminar, el plano queda preparado con el muro dibujado para continuar el trabajo.

## Casos borde a evitar en el video

- Si se cancela antes de seleccionar un segundo punto, no se crea ningun tramo.
- Si se selecciona dos veces el mismo punto, el tramo se ignora.
- La opcion Cerrar solo tiene sentido cuando ya hay varios tramos dibujados.
