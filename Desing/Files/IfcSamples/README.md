# IFC de ejemplo (Desing_2 — localización futura)

Este directorio guarda IFC de prueba para el flujo:

1. Buscar dirección  
2. Buscar / seleccionar edificio (Catastro)  
3. **Localizar IFC** (hoy: ejemplo fijo)  
4. Más adelante: importar con la app IFC externa

`SampleBuilding_Demo.ifc` es un IFC2X3 mínimo (caja) para probar el enlace RC → fichero.
Cuando se disponga, sustituir o complementar con modelos BuildingSMART (Duplex, etc.).
